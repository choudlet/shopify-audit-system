What Phase 1 Is Meant To Do

Phase 1 is the launch setup. The goal is to get the capture, tagging, and follow-up system in place before the busiest part of summer so Casa Crobu can begin building its own customer database and use that audience for stronger targeting during the non-market months.

This phase is not just about collecting names. It is about building the first version of the customer acquisition and retention system so market traffic can become usable email and SMS audience growth.


How Phase 1 Would Be Built

No matter which option is selected, the work is organized into the same core build steps.

1. Capture Foundation
A simple customer signup path is built for market use so shoppers can quickly join through a QR code flow and mobile-friendly form.

Capability being purchased:
A working first-party data capture system that can be used live at the market.

2. Consent and Audience Structure
The signup process is set up so customer information is collected cleanly and, where included, email and SMS consent are captured in a usable format.

Capability being purchased:
A customer list that can actually be marketed to later, rather than just a list of names.

3. Shopify and Klaviyo Setup
Customer tags, source fields, and basic segmentation are configured so new signups can be organized by where they came from and how they entered the system.

Capability being purchased:
Cleaner customer records and the ability to segment and target market shoppers later.

4. Welcome Messaging and Launch Offer
A welcome message or welcome flow is created, along with one launch offer, so new signups receive immediate follow-up after joining.

Capability being purchased:
An automated first-touch marketing sequence that starts building value from each signup right away.

5. Reporting, Team Use, and Launch QA
A simple dashboard, staff prompt or process, and end-to-end testing are completed before launch.

Capability being purchased:
Visibility into results and confidence that the system works before it is used live.

Main Difference Between Core and Recommended

Core Setup is a lighter first test. It gives Casa Crobu a basic capture and follow-up system so the business can start collecting customer data with a lower upfront investment.

Recommended Setup is the more complete version. It includes the setup, cleanup, tagging, and launch structure needed to make the pilot more useful long term.

Recommended Setup includes:
- Email and SMS capture from day one
- Existing consented list preparation
- Cleaner Shopify and Klaviyo structure
- Stronger source tagging
- A fuller launch workflow for the team


My Recommendation

I recommend Recommended Setup if the goal is to build the system correctly before July and give Casa Crobu the best chance of growing both email and SMS capture this season.

If Casa Crobu wants the simplest possible starting point, Core Setup is still a valid lean launch option.

The Member Lookup + POS Attribution Add-On is optional, but it becomes especially valuable if Casa Crobu wants to connect returning market shoppers back to Shopify customer profiles and improve attribution on repeat market orders.
